# RedactedValue

Фирменный компонент: показывает одно значение данных в одном из четырёх состояний обезличивания.

| Состояние | Вид | Когда |
| --- | --- | --- |
| `original` | Текст `mono` 400 цвета `ink`, без фона | Исходное значение, ещё не проверено |
| `detected` | Текст `mono` 400 цвета `ink` на плашке `highlight-soft`, `radius-bar`. Одиночное значение вне таблицы — `on-highlight` на яркой `highlight` | Найдены персональные данные, ещё не скрыты |
| `redacted` | Сплошная плашка `redact` той же ширины, что и значение, высота 14px, `radius-bar`; текст скрыт | Значение обезличено, замена не показывается |
| `token` | Токен в квадратных скобках `mono`, рамка `border` 1px, фон `surface-sunken`, `radius-bar` | Значение заменено псевдонимом (`[ИНН_01]`) |

Правила:

- Плашка `redacted` всегда цвета `redact` (= `ink`), никогда не цветная.
- В таблицах и списках `detected` — всегда мягкий `highlight-soft`: яркий маркер на каждом значении сливается в сплошное оранжевое поле.
- Ширина плашки примерно равна длине скрытого значения: структура строки сохраняется.
- У `redacted` обязательно `aria-label` с типом данных: «Скрыто: ИНН».
- Рядом с переходом `detected → redacted/token` можно показывать стрелку `→` цветом `ink-muted`.

Что передаёт потребитель: само значение, тип данных (ИНН, ФИО, телефон…) и состояние.
