# Проверка v6.3 — 2026-11-01

SheetJS 0.18.5 заменена официальной полной сборкой 0.20.3 с CDN SheetJS.
Файл не модифицирован; URL и SHA-256 — vendor/sheetjs.provenance.json.
Используется локально встроенная библиотека: сетевые зависимости не добавлены.
В Worker удалена отдельная загрузка старой урезанной cpexcel.

29 модульных тестов прошли: 24 прежних и 5 новых.
Проверены BIFF8 и BIFF5 Windows-1251/DOS-866, XML/HTML под расширением XLS,
ведущие нули и коды, кириллица, суммы и отрицательные числа, логические значения,
даты 1900/1904, формулы с нулевым результатом, объединения, ширина и скрытые листы.
Все прежние проверки обезличивания и восстановления таблиц, свободных листов,
Word и шифрования ключей прошли. Подробности — test-results.txt.

Chromium с offline=True:
- CSV → обезличить → скачать ключ Excel → восстановить; текст совпал с исходным.
- BIFF8 XLS → Worker → XLSX → обезличить → скачать ключ → восстановить;
  значения, даты и коды совпали с результатом исходного импорта.
- BIFF5 cp1251/cp866 прочитаны в настоящем Blob Worker; кириллица и нули сохранены.
- Шрифты загрузились; ошибок JavaScript и запросов HTTP(S) не было.

В UI-тесте логический столбец оставлен без текстовой псевдонимизации:
при такой псевдонимизации true/false возвращаются строками. Это воспроизведено
одинаково на ядрах 6.2 и 6.3 и не связано с обновлением SheetJS.
Логический тип при самом импорте и при оставлении столбца без замены сохраняется.
Полного перебора всех форматов и вариантов UI нет; случаи явно перечислены выше.

Ядро, формат ключа, Word и ExcelJS не менялись. Список изменённых файлов и диффы приложены.
Сохранённые HTML и сборка v6.2 остались с прежним SHA-256.
Размер HTML v6.3 вырос из-за полной библиотеки кодировок; точные байты — summary.json.

Сборка и приложение не требуют интернета. Никаких изменений в GitHub не отправлено.
