# Redact — обезличивание таблиц

Один HTML-файл, который скрывает чувствительные данные в Excel/CSV: названия контрагентов, ИНН, коды, суммы, даты.
Обработка идёт **полностью в браузере**: файл никуда не загружается, интернет не нужен.

## Как пользоваться

1. Откройте `Redact_vX.Y.html` (последняя версия) в браузере (Chrome, Edge, Firefox) — двойным щелчком.
2. Перетащите файл `.xlsx` / `.csv`. Инструмент сам найдёт строку заголовков (её можно поправить) и строки «Итого».
3. Для каждого столбца видны тип, примеры значений и число уникальных значений. Выберите метод
   (или нажмите «Автовыбор по названиям»).
4. Проверьте предпросмотр «было → стало» и нажмите «Обезличить и скачать» (результат — `<имя>_redact.xlsx`).
   При необходимости скачайте «ключ соответствий» и храните его **отдельно**.
5. Чтобы взять следующий файл, нажмите «Очистить» в шаге 1: файл и настройки столбцов уберутся,
   общие параметры (ключ, K, D) останутся.

## Методы

| Тип | Метод | Что делает |
|---|---|---|
| Текст | Псевдоним с номером | `ОПТТРЕЙД ООО` → `Контрагент 047 ООО`. Одинаковые названия → одинаковый псевдоним, ОПФ сохраняется |
| Текст | Вымышленное название | `ОПТТРЕЙД ООО` → `ТРАНСГАРАНТ ООО` |
| Текст | Замена внутри текста | В свободном тексте («Договор», «Документ расчётов») заменяет найденные названия/ИНН из других столбцов, сдвигает даты на D и меняет номера из 3+ цифр |
| Текст / код | Маска | Каждая буква → случайная буква, цифра → цифра; формат сохраняется |
| Код / ИНН | Случайные цифры | `000001658` → `000003708`, `00/001455` → `00/002848`: длина, разделители и ведущие нули сохраняются |
| Любой | Хэш-код, Очистить | `ID-3K9F…` или пустая ячейка |
| Число | Умножить на K | Все выбранные числовые столбцы умножаются на **одно** число: структура, доли, суммы и «Итого» остаются согласованными |
| Число | Шум ±%, Округлить, Случайное | Для случаев, когда пропорции тоже нужно скрыть |
| Дата | Сдвиг на общий D дней | Все даты сдвигаются одинаково — сроки, просрочка, распределение по корзинам ПДЗ сохраняются. Работает и с датами-текстом (`30.09.2026`) |
| Дата | До месяца, Случайная | Обобщение или полная замена |

## Восстановление по ключу

Сценарий «туда и обратно»: обезличенный файл уходит аналитику, аудитору или в ИИ-сервис, а результат их работы
возвращается к настоящим названиям.

1. При обезличивании в шаге 4 скачайте **ключ соответствий**. С паролем (от 8 символов) ключ сохраняется
   зашифрованным файлом `.redactkey` (AES-256-GCM, ключ шифрования получается из пароля через PBKDF2-SHA256,
   600 000 итераций); без пароля — таблицей Excel `_KEY.xlsx`, которую может открыть любой.
2. Вкладка «Восстановить по ключу»: выберите обезличенный или присланный в ответ файл и ключ (для `.redactkey` — пароль).
3. Столбцы сопоставляются по названиям, поэтому в ответном файле их можно переставлять, удалять и добавлять свои.
   Для каждого столбца предлагается действие: «Вернуть значения», «Вернуть в тексте», «Разделить на K»,
   «Сдвинуть даты на −D» или «Оставить». Псевдонимы возвращаются и внутри нового текста
   («Контрагент 047 ООО: просрочка» → «ОПТТРЕЙД ООО: просрочка»), на остальных листах книги тоже.
4. Предпросмотр «замена → исходное», предупреждение о псевдонимах, которых нет в ключе, кнопка «Восстановить и скачать»
   (результат — `<имя>_restored.xlsx`).

Обезличенный файл возвращается **один в один**: названия, коды, номера в тексте, даты и суммы (для сумм ключ хранит
точную таблицу, поэтому ошибки округления нет). Необратимы только методы, которые для этого и предназначены:
шум, округление, случайные значения, обобщение до месяца и очистка. Новые числа, посчитанные в ответном файле
(например, «Резерв 50%»), можно разделить на K — это даст исходный масштаб с точностью до копейки.

Ключи, сохранённые версиями до 2.1 (`_KEY.xlsx` без скрытого листа), тоже открываются: названия и коды вернутся,
номера внутри текста — нет.

## Полезное

- **Секретный ключ.** Замены детерминированы: тот же ключ → те же псевдонимы. Если каждый месяц использовать
  один ключ, «Контрагент 047» будет одним и тем же контрагентом во всех выгрузках. Не передавайте ключ вместе с файлом.
- **Словарь.** Столбцы с одинаковым именем словаря получают одинаковые замены (например, «Покупатель» и «Грузополучатель»).
- **Файл настроек (JSON).** Кнопка «Сохранить настройки» записывает методы по столбцам, лист, строку заголовков
  и флажки в `Redact_settings_<файл>.json`. В следующий раз нажмите «Загрузить настройки» — до или после
  загрузки данных. Столбцы сопоставляются по названию (если названия нет — по букве), отсутствующие в файле
  столбцы перечисляются. Ключ, K и D попадают в JSON только при включённом флажке — такой файл храните отдельно.
  Кроме того, браузер сам запоминает настройки для файлов с такой же структурой столбцов.
- **Сохранение оформления.** Результат пишется в копию исходной книги: форматы чисел, ширина столбцов,
  объединённые ячейки и стили сохраняются. Формулы остаются, их кэш убирается — Excel пересчитает при открытии.
- **Защита от утечек.** Очищаются свойства файла (автор, компания), примечания и колонтитулы (картинки в колонтитулах тоже не переносятся); другие листы удаляются;
  инструмент предупреждает, если исходные названия встречаются в столбцах, оставленных без изменений.

## Ограничения

- Старый формат `.xls` нужно пересохранить в `.xlsx`.
- «Нестандартные» xlsx (например, из 1С) чинятся автоматически; если в них были картинки в нестандартном
  формате, они удаляются из результата (данные не затрагиваются).
- Это псевдонимизация (в терминах 152-ФЗ — обезличивание методом введения идентификаторов): по ключу данные
  восстанавливаются, поэтому ключ храните отдельно от файла и лучше с паролем. При очень малом числе контрагентов
  и известных суммах данные можно сопоставить и без ключа — для внешней передачи используйте метод K для сумм.
- Сводные таблицы и диаграммы внутри книги ExcelJS может не сохранить — лучше обезличивать «плоскую» выгрузку.

## Разработка

```
brand/           брендбук Redact: BRAND.md, токены, логотипы, правила компонентов
src/version.js   номер версии
src/index.html   разметка
src/style.css    стили (только токены из brand/tokens.css)
src/fonts/       шрифты бренда (Golos Text, JetBrains Mono, Rubik Mono One; SIL OFL), встраиваются при сборке
src/icons/       SVG-иконки (Lucide, ISC); build.py собирает из них спрайт
src/engine.js    логика (без DOM, можно запускать в Node)
src/app.js       интерфейс обезличивания
src/restore.js   интерфейс восстановления по ключу
src/dropdown.js  выпадающие списки в стиле Redact вместо системных
tests/           автотесты: обезличивание → ключ → восстановление (node --test tests/)
vendor/          ExcelJS 4.4.0 (MIT), JSZip 3.10.2 (MIT), лицензия Lucide
build.py         собирает всё в один файл Redact_vX.Y.html
```

Для разработки откройте `src/index.html`, после правок выполните `python3 build.py` и `node --test tests/`
(тесты не требуют установки зависимостей и работают на синтетических данных).

**Дизайн.** Все правила — в `brand/BRAND.md`: цвета, отступы, скругления и шрифты только через токены,
интерфейс монохромный, жёлтый маркер — только для найденных данных, термин — «обезличивание».

**Иконки.** Только SVG, без эмодзи и иконочных шрифтов. Чтобы добавить иконку, положите её `.svg`
из [Lucide](https://lucide.dev/icons) в `src/icons/` и используйте в разметке
`<svg class="i"><use href="#i-имя-файла"></use></svg>` (в JS — `icon('имя')`), затем `python3 build.py`.

**Версии.** Каждая доработка повышает версию на 0.1 (1.0 → 1.1 → … → 1.9 → 2.0): меняется `src/version.js`,
собирается новый `Redact_vX.Y.html` (предыдущий удаляется — старые версии есть в истории git),
изменения описываются в `CHANGELOG.md`.
