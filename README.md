# Redact — обезличивание таблиц

Один HTML-файл, который скрывает чувствительные данные в Excel/CSV: названия контрагентов, ИНН, коды, суммы, даты.
Обработка идёт **полностью в браузере**: файл никуда не загружается, интернет не нужен.

Страница проекта — `index.html` (для GitHub Pages): что делает Redact, пример «было → стало» и ссылка на последнюю версию.

## Как пользоваться

1. Откройте `Redact_vX.Y.html` (последняя версия) в браузере (Chrome, Edge, Firefox) — двойным щелчком.
2. Перетащите файл `.xlsx`, `.xls` или `.csv`. Инструмент сам найдёт строку заголовков (её можно поправить) и строки «Итого».
3. Для каждого столбца видны тип, примеры значений и число уникальных значений. Выберите метод
   (или нажмите «Автовыбор по названиям»).
4. Проверьте предпросмотр «было → стало» и нажмите «Обезличить и скачать» (результат — `<имя>_redact.xlsx`).
   При необходимости скачайте «ключ соответствий» и храните его **отдельно**.
5. Чтобы взять следующий файл, нажмите «Очистить» в шаге 1 и подтвердите: файл и настройки столбцов уберутся,
   общие параметры (секретная фраза, коэффициент, сдвиг дат) останутся.

## Методы

| Тип | Метод | Что делает |
|---|---|---|
| Текст | Псевдоним с номером | `ВЕРЕСКОВ ООО` → `Контрагент 047 ООО`. Одинаковые названия → одинаковый псевдоним, форма организации (ООО, АО) сохраняется |
| Текст | Вымышленное название | `ВЕРЕСКОВ ООО` → `ТРАНСГАРАНТ ООО` |
| Текст | Замена внутри текста | В свободном тексте («Договор», «Документ расчётов») заменяет найденные названия/ИНН из других столбцов (ФИО — и с инициалами: `ИП Иванов И. И.`), сдвигает даты и меняет номера из трёх и более цифр |
| Текст / код | Маска | Каждая буква → случайная буква, цифра → цифра; формат сохраняется |
| Код / ИНН | Случайные цифры | `000001658` → `000003708`, `00/001455` → `00/002848`: длина, разделители и ведущие нули сохраняются |
| Любой | Код-идентификатор, Очистить | `ID-3K9F…` или пустая ячейка |
| Число | Умножить на коэффициент | Все выбранные числовые столбцы умножаются на **одно** число: структура, доли, суммы и «Итого» остаются согласованными |
| Число | Шум ±%, Округлить, Случайное | Для случаев, когда пропорции тоже нужно скрыть |
| Дата | Сдвинуть даты | Все даты сдвигаются одинаково — сроки, просрочка, распределение по корзинам ПДЗ сохраняются. Работает и с датами-текстом (`30.09.2026`) |
| Дата | До месяца, Случайная | Обобщение или полная замена |

## Книга из нескольких листов

- Все листы книги разбираются сразу; в списке «Лист» видно, сколько столбцов обезличивается на каждом
  («ДЗ · 6 столбцов», «КЗ · не обезличивается»). Методы задаются для каждого листа отдельно и не сбрасываются
  при переключении.
- Однотипные столбцы на разных листах (контрагенты, ИНН, коды контрагентов, организация) автоматически
  получают общую группу замен: одна и та же компания на «ДЗ» и «КЗ» станет одним псевдонимом.
- «Обезличить и скачать» обрабатывает все листы с методами. Листы без методов по умолчанию удаляются из
  результата; флажок «Удалять из результата листы, которые не обезличиваются» на шаге 3 позволяет оставить их как есть.
- Ключ соответствий и файл настроек — общие на всю книгу; при восстановлении все листы из ключа
  возвращаются полностью, а действия можно проверить для каждого листа.
- Для книги из одного листа замены те же, что в прежних версиях: с той же секретной фразой псевдонимы совпадут.

## Для внешней передачи

Кнопка «Для внешней передачи» в шаге 4 — для файла, который уходит наружу и возвращать который не нужно.
После подтверждения в диалоге Redact обезличивает файл заново:

- секретная фраза, коэффициент и сдвиг дат — одноразовые, случайные: они нигде не показываются и не сохраняются,
  ключ соответствий не создаётся. Вернуть данные по такому файлу нельзя никому, в том числе вам;
- псевдонимы другие, чем в файлах с вашей постоянной фразой, — сопоставить выгрузки между собой тоже нельзя;
- денежные столбцы («Сумма», «Задолженность», «Резерв», «ПДЗ…»), оставленные на шаге 2 как есть, тоже умножаются
  на коэффициент; счётчики и ставки («Кол-во дней», «Ставка, %») не трогаются;
- столбцы дат, оставленные как есть, сдвигаются на одноразовое число дней — сроки и просрочка сохраняются;
- свойства файла, примечания, колонтитулы и листы без методов удаляются независимо от флажков шага 3.

Результат — `<имя>_external.xlsx`. Обычная выгрузка и ключ при этом не меняются.

## Восстановление по ключу

Сценарий «туда и обратно»: обезличенный файл уходит аналитику, аудитору или в ИИ-сервис, а результат их работы
возвращается к настоящим названиям.

1. При обезличивании в шаге 4 скачайте **ключ соответствий**. С паролем (от 8 символов) ключ сохраняется
   зашифрованным файлом `.redactkey` (AES-256-GCM, ключ шифрования получается из пароля через PBKDF2-SHA256,
   600 000 итераций); без пароля — таблицей Excel `_KEY.xlsx`, которую может открыть любой.
2. Вкладка «Восстановить по ключу»: выберите обезличенный или присланный в ответ файл и ключ (для `.redactkey` — пароль).
3. Столбцы сопоставляются по названиям, поэтому в ответном файле их можно переставлять, удалять и добавлять свои.
   Для каждого столбца предлагается действие: «Вернуть значения», «Вернуть в тексте», «Вернуть суммы»,
   «Вернуть даты» или «Оставить». Псевдонимы возвращаются и внутри нового текста
   («Контрагент 047 ООО: просрочка» → «ВЕРЕСКОВ ООО: просрочка»), на остальных листах книги тоже.
4. Предпросмотр «замена → исходное», предупреждение о псевдонимах, которых нет в ключе, кнопка «Восстановить и скачать»
   (результат — `<имя>_restored.xlsx`).

Обезличенный файл возвращается **один в один**: названия, коды, номера в тексте, даты и суммы (для сумм ключ хранит
точную таблицу, поэтому ошибки округления нет). Необратимы только методы, которые для этого и предназначены:
шум, округление, случайные значения, обобщение до месяца и очистка. Новые числа, посчитанные в ответном файле
(например, «Резерв 50%»), можно вернуть действием «Вернуть суммы» (деление на коэффициент) — это даст исходный масштаб с точностью до копейки.

Ключи, сохранённые версиями до 2.1 (`_KEY.xlsx` без скрытого листа), тоже открываются: названия и коды вернутся,
номера внутри текста — нет.

## Полезное

- **Секретная фраза.** Замены детерминированы: та же фраза → те же псевдонимы. Если каждый месяц использовать
  одну фразу, «Контрагент 047» будет одним и тем же контрагентом во всех выгрузках. Держите фразу в секрете и не передавайте её вместе с файлом.
- **Группа замен.** Одинаковые значения в столбцах одной группы получают одинаковую замену: укажите одну группу
  у «Покупателя» и «Грузополучателя» — одна компания в обоих станет одним псевдонимом. По умолчанию группа — буква столбца.
- **Файл настроек (JSON).** Кнопка «Сохранить настройки» записывает методы по столбцам, лист, строку заголовков
  и флажки в `Redact_settings_<файл>.json`. В следующий раз нажмите «Загрузить настройки» — до или после
  загрузки данных. Столбцы сопоставляются по названию (если названия нет — по букве), отсутствующие в файле
  столбцы перечисляются. Секретная фраза, коэффициент и сдвиг дат попадают в JSON только при включённом флажке — такой файл храните отдельно.
  Кроме того, браузер сам запоминает настройки для файлов с такой же структурой столбцов.
- **Сохранение оформления.** Результат пишется в копию исходной книги: форматы чисел, ширина столбцов,
  объединённые ячейки и стили сохраняются. Формулы остаются, их кэш убирается — Excel пересчитает при открытии.
- **Защита от утечек.** Очищаются свойства файла (автор, компания), примечания и колонтитулы (картинки в колонтитулах тоже не переносятся); другие листы удаляются;
  инструмент предупреждает, если исходные названия встречаются в столбцах, оставленных без изменений.

## Ограничения

- Файлы `.xls` (Excel 97–2003, Excel 5.0/95, XML Excel 2003 и HTML-таблицы из учётных систем) открываются,
  но переводятся в `.xlsx`: значения, формулы, форматы чисел, ширина столбцов, высота строк и объединённые ячейки
  переносятся, а шрифты, заливка и рамки — нет. Результат сохраняется в `.xlsx`. Файл `.xls` с паролем нужно
  сначала открыть в Excel и снять защиту.
- «Нестандартные» xlsx (например, из учётных систем) чинятся автоматически; если в них были картинки в нестандартном
  формате, они удаляются из результата (данные не затрагиваются).
- Это псевдонимизация (в терминах 152-ФЗ — обезличивание методом введения идентификаторов): по ключу данные
  восстанавливаются, поэтому ключ храните отдельно от файла и лучше с паролем. Для передачи наружу — кнопка
  «Для внешней передачи» (без ключа).
- Умножение на коэффициент сохраняет пропорции: если получатель знает несколько точных сумм, по ним можно вычислить
  коэффициент. В таком случае выбирайте для сумм «Случайное отклонение ±%».
- Сводные таблицы и диаграммы внутри книги ExcelJS может не сохранить — лучше обезличивать «плоскую» выгрузку.

## Разработка

```
brand/           брендбук Redact: BRAND.md, токены, логотипы, правила компонентов
src/version.js   номер версии
src/index.html   разметка
src/landing.html страница проекта (build.py собирает из неё index.html) и её стили src/landing.css
src/style.css    стили (только токены из brand/tokens.css)
src/fonts/       шрифты бренда (Golos Text, JetBrains Mono; SIL OFL), встраиваются при сборке
src/icons/       SVG-иконки (Lucide, ISC); build.py собирает из них спрайт
src/engine.js    логика (без DOM, можно запускать в Node)
src/app.js       интерфейс обезличивания
src/restore.js   интерфейс восстановления по ключу
src/dropdown.js  выпадающие списки в стиле Redact вместо системных
src/tooltip.js   подсказки в стиле Redact вместо системных
src/dialog.js    диалог подтверждения необратимых действий
src/xls.js       чтение .xls через SheetJS в фоновом потоке и перевод в .xlsx
tests/           автотесты: обезличивание → ключ → восстановление (node --test tests/*.test.js)
vendor/          ExcelJS 4.4.0 (MIT), JSZip 3.10.2 (MIT), SheetJS 0.18.5 (Apache-2.0, для .xls), лицензия Lucide
build.py         собирает всё в один файл Redact_vX.Y.html и страницу index.html
```

Для разработки откройте `src/index.html`, после правок выполните `python3 build.py` и `node --test tests/*.test.js`
(тесты не требуют установки зависимостей и работают на синтетических данных).

**Дизайн.** Все правила — в `brand/BRAND.md`: цвета, отступы, скругления и шрифты только через токены,
интерфейс монохромный, жёлтый маркер — только для найденных данных, термин — «обезличивание».

**Иконки.** Только SVG, без эмодзи и иконочных шрифтов. Чтобы добавить иконку, положите её `.svg`
из [Lucide](https://lucide.dev/icons) в `src/icons/` и используйте в разметке
`<svg class="i"><use href="#i-имя-файла"></use></svg>` (в JS — `icon('имя')`), затем `python3 build.py`.

**Версии.** Каждая доработка повышает версию на 0.1 (1.0 → 1.1 → … → 1.9 → 2.0): меняется `src/version.js`,
собирается новый `Redact_vX.Y.html` (предыдущий удаляется — старые версии есть в истории git),
изменения описываются в `CHANGELOG.md`.
