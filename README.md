# Redact v6.3

Обновление восстановленной v6.2: SheetJS 0.18.5 → 0.20.3 для импорта старых XLS.
Полная библиотека встроена в HTML вместе со всеми кодировками и запускается только в Worker.
Интернет для работы приложения и сборки не нужен. В этой ветке опубликованы исходники и готовый HTML v6.3; основная ветка не изменяется.

## Сборка

```sh
python3 build.py
```

Результат сборки: `dist/Redact_v6.3.html`. Готовая копия также опубликована в корне: `Redact_v6.3.html`.
`index.html` в корне ссылается на v6.3; исходный шаблон landing.html сохранён от v5.8 и новым сборщиком не обрабатывается.
Нужен Python 3; сторонних пакетов нет. Сборщик не меняет original/ или исходники.
`src/index.html` — шаблон с FILE/DATA-маркерами; JS/CSS лежат отдельно в src/ и vendor/,
SVG и WOFF2 — в src/assets/. Шаблон напрямую в браузере не запускается.

## Проверки

```sh
node --test tests/*.test.js
python3 tests/browser_offline.py
```

Модульные тесты: Node.js 24, зависимости не нужны. Всего 29 тестов.
Браузерная проверка требует Python Playwright и Chromium (/usr/bin/chromium).
Тест загружает HTML через set_content в offline=True и проверяет CSV/XLS:
импорт, обезличивание, скачивание ключа XLSX, восстановление, а также Worker Windows-1251/DOS-866.
Результаты текущего выпуска — validation/. Для подробных результатов Node каждый файл запускается отдельно.

## Зависимости и происхождение

`vendor/sheetjs.provenance.json` фиксирует официальный URL, версию и SHA-256 загруженного файла.
Полная SheetJS 0.20.3 сохранена без изменений; лицензия — vendor/sheetjs.LICENSE.
Документация: https://docs.sheetjs.com/docs/getting-started/installation/standalone/

- original/Redact_v6.2.html — сохранённый загруженный HTML, не изменён.
- recovery/ — исторические отчёты восстановления 6.2, включая её хеши и тесты; это не отчёты 6.3.
- reference-v5.8/ — материалы репозитория ygadalov/anonymizer_project на коммите
  791baf048edbdb82921b3687154d098121a0c8d8; в приложенном HTML их не было.
- 23 исходных теста перенесены из v5.8, 1 добавлен при восстановлении 6.2,
  5 тестов совместимости и расширение браузерного теста написаны для 6.3.
- build.py, README, CHANGELOG и служебные отчёты созданы отдельно, а не извлечены из HTML.
- Имена некоторых восстановленных модулей назначены при извлечении; детали — recovery/.

## Известное ограничение

Уже в v6.2 текстовая псевдонимизация логических ячеек true/false возвращала по ключу строки
"true"/"false", а не логический тип. В 6.3 это поведение не менялось. Если тип важен,
для такого столбца выбирайте «Оставить как есть». Импорт XLS сохраняет логический тип;
в браузерном roundtrip-тесте этот столбец оставлен без замены.
