# Результат восстановления v6.2

Сравнение с v5.8 выполнено до извлечения, старый build.py не запускался.
Базовый коммит: 791baf048edbdb82921b3687154d098121a0c8d8.
Сохранён оригинал и его SHA-256; повторная сборка полностью совпадает:
303a8eda4cbefaf1c80746111fa25858e7aa5138874c97bf22a42c2e53e58b0f.

Извлечены 5 блоков CSS, 21 блок JavaScript (включая библиотеки и Worker-код),
разметка с SVG-спрайтом, встроенные SVG и WOFF2. Новые имена модулей — реконструкция.

Сравнение блоков: comparison-v5.8.json; диффы модулей — diffs/.
Статус fonts.css «changed» включает преобразование внешних путей шрифтов в data URI;
его нельзя считать доказательством изменения дизайна. manifest.json содержит соответствия
декодированных ассетов файлам v5.8 по SHA-256.

24 теста пройдены: Word 9, свободные листы 3, таблицы/ключи 8, XLS 3, ограничения 1.
23 теста происходят из v5.8; тест ограничений создан при восстановлении.
Функциональные тесты выполняются на извлечённых модулях v6.2 и её библиотеках.

Chromium: offline=True, HTML передан через set_content (не file://).
Проверены шрифты, версия, запуск интерфейса и Worker проверки ZIP.
Полный сценарий CSV: загрузка → «Обезличить всё» → скачать → скачать ключ XLSX →
восстановить по ключу. Обе организации исчезли из результата; восстановленный CSV
совпал с исходным (за исключением допустимых BOM/завершающего перевода строки).
Ошибок JavaScript и запросов HTTP(S) не было.
Работа остальных файловых сценариев проверена модульными тестами, а не всеми путями UI.

После восстановления CDN SheetJS проверен через HTTPS: HTTP/2 200.
Первоначальная попытка в ограниченном процессе не достигла proxy:8080;
повторная проверка в разрешённом процессе через тот же прокси успешна.
Результат HEAD — sheetjs-network.txt. CDN также читается через веб-инструмент.
Библиотека осталась 0.18.5. Обновление не включалось в восстановление.

README, CHANGELOG, build.py, recovery/ и новые проверки написаны отдельно.
Исторические документы, тесты, лицензии и служебные файлы из v5.8 сохранены
в reference-v5.8 с явным указанием происхождения. Невстроенные материалы v6.2
нельзя достоверно извлечь; история 5.9–6.1 не выдумывалась.

Версия остаётся 6.2; следующая доработка — 6.3. Записей в GitHub не выполнялось.
