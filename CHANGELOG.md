# История версий

## v1.2 — 2026-10-16
- Исправлено: ошибка «Cannot read properties of undefined (reading 'anchors')» при загрузке некоторых xlsx
  (например, выгрузок из 1С). Причина — рисунок листа, записанный без префикса пространства имён,
  который не умеет читать ExcelJS.
- Если файл не читается, инструмент автоматически чинит его копию в памяти (отвязывает нестандартный рисунок)
  и читает повторно; что именно исправлено — показывается в предупреждениях шага 4. Данные не затрагиваются.
- Добавлена библиотека JSZip 3.10.2 (MIT) для починки файлов.

## v1.1 — 2026-10-16
- Эмодзи заменены на SVG-иконки из открытого набора Lucide (лицензия ISC): логотип, загрузка файла,
  кнопки настроек, автовыбора, сброса, случайных значений, предпросмотра, скачивания, ключа; предупреждения и уведомления.
- Иконки встроены в HTML SVG-спрайтом — работает офлайн, цвет подстраивается под светлую/тёмную тему.
- Исходники иконок лежат в `src/icons/`, спрайт собирает `build.py`.

## v1.0 — 2026-10-16
- Первая версия с номером. Файл инструмента: `Anonymizer_v1.0.html`.
- Сохранение и загрузка настроек анонимизации в JSON: методы и параметры столбцов, лист, строка заголовков,
  флажки; по желанию — ключ, K и D.
- Настройки можно загрузить до файла с данными: они применятся при его загрузке.
- Сопоставление столбцов по названию с запасным вариантом по букве; выводится список столбцов, которых нет в файле.
- Номер версии отображается в заголовке страницы и записывается в файл настроек.

## Без номера (первоначальная)
- Загрузка .xlsx/.csv, автоопределение заголовков, типов столбцов и строк «Итого».
- Методы: псевдонимы, вымышленные названия, маска, случайные цифры, замена внутри текста, хэш,
  общий коэффициент K, шум, округление, сдвиг дат D, обобщение до месяца.
- Предпросмотр, выгрузка с сохранением оформления, ключ соответствий.
